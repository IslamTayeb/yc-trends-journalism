# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Journalism data project: how YC batch composition changed over time. Phase 1 (done) uses only YC's native labels plus YC's Requests for Startups. No LLM classification, no invented categories, no merging of YC labels, no causal language in outputs.

## Commands

```bash
uv sync
scripts/fetch_sources.sh        # (re)download sources; needs network
uv run python run_all.py        # full pipeline (~40 s): data/processed, data/quality, figures/, report.md, yc_native_analysis.xlsx
START_YEAR=2016 OUT_DIR=out16/processed FIG_DIR=out16/figures uv run python run_all.py
```

No tests. `run_all.py` is the check: it aborts on spot-check mismatches and must print `cross-check mismatches: 0`. Modules need `src` on the path (`PYTHONPATH=src uv run python -m ycnative.<module>`).

## Architecture

`run_all.py` builds one `ctx` dict through `src/ycnative/` stages in order: `load` (raw fields verbatim, derived fields prefixed `n_`) -> `batches` (sets `is_partial_batch` and `low_tag_coverage`, which downstream stages use to exclude batches from rankings and tag stats) -> `trends`/`emergence`/`rankings` run generically for industry, subindustry, tag -> `cooccurrence`, `geography`, `diversity`, `taxonomy_history` (diffs monthly snapshots), `enrichment`, `rfs`, `quality`, `figures`, `workbook`, `report`.

`report.md` is generated by `report.py` from DataFrames; edit the generator, not the markdown. Thresholds live in `config.yaml`.

## Data gotchas

- YC retroactively relabels companies; `AI` and `Artificial Intelligence` are swapped constantly. Keep them separate but treat as one measurement.
- Winter 2026 and Spring 2026 are ~75% zero-tag; pre-2011 batches too.
- yc-oss/api history starts 2024-08-22. Wayback `id_` captures may be gzipped; the live `/rfs` page shows only the current edition.

## Hygiene

Raw HTML, clones and snapshot blobs are gitignored (a committed YC page once tripped GitHub secret scanning). Commit and push at checkpoints. Deliver files with the `deliver-to-mac` skill.
