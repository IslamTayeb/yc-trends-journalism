# Op-ed figures

Three figures for the "YC turned from B2B SaaS toward the physical world" piece, styled to imt.sh. Everything here is
regenerated by one script; edit the script, not the outputs.

```bash
uv run python blog/make_figures.py                # CSVs, SVGs, preview.html, PNG (light+dark, 2x) and PDF via headless Chrome
uv run python blog/make_figures.py --no-raster    # SVGs only
uv run python blog/make_figures.py --embed-fonts  # base64 Open Sans inside each SVG (~600 KB each) for viewers without the font
```

The script prints the headline numbers (B2B peak, Industrials W19 vs S26, fitted slopes) so they can be checked against
the dashboard before quoting them.

## Files

| path | what |
|---|---|
| `data/yc_industry_share_w19_f26.csv` | one row per batch x top-level industry, W19 to F26: count, total companies, share of batch, partial flag, trend segment, rank |
| `data/google_trends_ai_llm_gpt_worldwide_2018_2026.csv` | monthly worldwide index for "ai", "llm", "gpt", Sep 2018 to Sep 2026; `<1` stored as 0.5 and flagged in `lt1_flags` |
| `figures/yc_b2b_vs_industrials.svg` | Fig 1: share of batch, B2B and Industrials highlighted, two least-squares segments (W19 to S22, W23 to S26), ChatGPT rule |
| `figures/yc_industry_rank.svg` | Fig 2: bump chart of industry rank by count within batch |
| `figures/ai_search_interest.svg` | Fig 3: three stacked Google Trends panels with GPT-3 and ChatGPT rules |
| `figures/*_light.png`, `*_dark.png` | 1600 px wide rasters of each figure in both themes |
| `figures/*.pdf` | vector PDFs (text selectable) for the assignment |
| `figures/preview.html` | all three inline with a light/dark toggle; `?fig=2&theme=dark` shows one figure alone (used for the rasters) |
| `fonts/` | Open Sans TTFs, gitignored; fetch with the curl line below and symlink into `~/.local/share/fonts` so Chrome uses them |

```bash
for f in OpenSans-Regular OpenSans-SemiBold OpenSans-Bold; do
  curl -sfL "https://github.com/googlefonts/opensans/raw/main/fonts/ttf/$f.ttf" -o blog/fonts/$f.ttf; done
```

## Using the SVGs on the site

Every colour in the SVGs is `var(--token, fallback)` using the site's own token names (`--background`, `--foreground`,
`--muted-foreground`, `--border`, `--page-rule`, `--roy-r/o/y/b`). Inline the SVG in MDX and it follows the theme
toggle with no extra CSS; the `.dark` ancestor selector and `prefers-color-scheme` are both honoured. As a standalone
`<img>` or file it uses the fallbacks (light palette, dark under a dark OS theme). Points and lines carry `<title>`
elements, so hovering shows batch, label and value when inline. No scripts, no external references.

Widths are `viewBox` 800 with `width="100%"`, sized for the 768 px content column.

## Data notes

- Share = companies carrying the industry label / all companies in the batch (same denominator as the dashboard and
  `data/all_years/processed/yc_industry_trends.csv`). A company can carry more than one industry label.
- F26 has 35 companies and is flagged partial: hollow marker, excluded from the fits. W27 (1 company) is dropped.
- Rank ties are broken alphabetically. The dashboard uses pandas `method="first"`, which gives the same result on this
  window because ties only occur at zero.
- Google Trends indexes each term to its own peak, so the three rows in Fig 3 compare in shape, not level. "gpt" is
  below 1 every month until Nov 2022 (the Jul 2020 GPT-3 spike is visible only in the separately normalised
  `data/raw/google_trends/google_trends_gpt-3_worldwide_monthly_2017-2022.csv`).
